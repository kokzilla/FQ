# ระบบประเมินผลการปฏิบัติงานบุคลากรประจำอาคาร (แม่บ้าน)
### มหาวิทยาลัยราชภัฏบุรีรัมย์ (BRU Building Facility Evaluation System)

เว็บแอปพลิเคชันรูปแบบ **Mobile-First Responsive Web Application (PWA)** ออกแบบสไตล์ **Minimalist** ใช้งานง่าย สะอาดตา และคล่องตัว สำหรับตรวจประเมินมาตรฐานความสะอาดและความเรียบร้อยของอาคารสถานที่ มหาวิทยาลัยราชภัฏบุรีรัมย์

---

## 🚀 ฟังก์ชันหลักของระบบ (System Highlights)

### 1. ระบบยืนยันตัวตนก่อนเข้าใช้งาน (Mandatory Login / Auth Guard)
- บังคับเข้าสู่ระบบก่อนเข้าใช้งานทุกหน้าจอ หากยังไม่ได้ล็อกอินจะถูกนำทางไปยัง `/login` โดยอัตโนมัติ
- รองรับการยืนยันตัวตนผ่าน **BRU SSO API** (`https://sso.bru.ac.th`) และบัญชีผู้ดูแลระบบ (`admin` / `admin`)

### 2. การจัดการรอบการประเมิน (Evaluation Rounds)
- สามารถสร้างรอบประเมินได้อิสระ (เช่น รอบปีงบประมาณ 2568, รอบปี 2570)
- คะแนนในแต่ละรอบเป็นอิสระต่อกัน (Independent Cycle) ไม่นำคะแนนมารวมกัน
- มีสถานะรอบ: `🟢 กำลังเปิดรับการประเมิน (OPEN)` และ `⚪ ปิดรอบแล้ว (CLOSED)`

### 3. การประเมินโดยคณะกรรมการหลายคน (Multi-Auditor Item-Level Consensus)
- ใน 1 รอบการประเมิน อาคารเดียวกันสามารถมีกรรมการหลายคนเข้าตรวจแยกกันได้
- ระบบจะนำคะแนนของกรรมการทุกคนมา **เฉลี่ยกันในระดับรายข้อย่อย (Item-Level Average)** ทำให้ได้ผลคะแนนรวมและคะแนนแต่ละหมวดที่สะท้อนมติของคณะกรรมการอย่างละเอียดและเป็นธรรมที่สุด

### 4. แผงควบคุมผู้ดูแลระบบ (Admin Console - `/admin`)
- **แท็บ 1: รอบการประเมิน**: สร้าง/แก้ไข/เปิด-ปิดรอบการประเมิน
- **แท็บ 2: ดึงข้อมูล SSO กำหนดกรรมการ**: ค้นหาบุคลากรผ่าน BRU SSO API แบบ Live Search แล้วกดแต่งตั้งเป็นคณะกรรมการ (Auditor) หรือผู้รับผิดชอบอาคาร (Housekeeper) ได้ทันที
- **แท็บ 3: อาคารและแม่บ้าน**: เพิ่ม/ลบอาคาร และกำหนดแม่บ้านประจำแต่ละอาคาร
- **แท็บ 4: จัดการข้อคำถามในหมวด**: เพิ่ม/ลบข้อคำถามในหมวด 1-7 แบบไดนามิก

### 5. เมนูรายงานสำหรับคณะกรรมการ (Committee Reports - `/reports`)
- **รายงานที่ 1: สรุปคะแนนการประเมินเฉลี่ยของแต่ละอาคาร (Building Average Score Summary)**:
  - สรุปคะแนนเฉลี่ยรวม, ร้อยละ, เกรดประเมิน, จำนวนและรายชื่อกรรมการที่ตรวจ, และจุดบกพร่องเร่งด่วน
- **รายงานที่ 2: เปรียบเทียบแนวโน้มการเปลี่ยนแปลงข้ามรอบ (Cross-Round Trend Comparison)**:
  - เปรียบเทียบคะแนนเฉลี่ยระหว่างรอบปัจจุบันกับรอบก่อนหน้า แสดงส่วนต่าง (+/- %) และตัวชี้วัดพัฒนาการ (📈 ดีขึ้น / 📉 ลดลง / ➖ คงที่)
- **รายงานที่ 3: วิเคราะห์จุดบกพร่องและความเสี่ยงเร่งด่วนตามหมวด (Defect & Risk Hotspots)**:
  - จัดอันดับหมวดที่มีคะแนนต่ำสุดและตรวจพบข้อบกพร่องสะสมมากที่สุด เพื่อนำเสนอเชิงนโยบายแก่ฝ่ายบริหาร
- **ส่งออกรายงาน**: ดาวน์โหลดข้อมูลตาราง Excel (.csv with UTF-8 BOM) ได้ในคลิกเดียว

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Framework**: [Nuxt 3](https://nuxt.com/) (Vue 3, TypeScript, Nitro Server Engine)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Prompt Font (Google Fonts)
* **Database & ORM**: [PostgreSQL](https://www.postgresql.org/) + [Prisma ORM](https://www.prisma.io/)
* **Offline Draft**: `localStorage` Auto-save
* **Digital Signature**: HTML5 Canvas Touch Signature Pad
* **Authentication**: BRU SSO API Integration

## ⚡ วิธีการเริ่มใช้งาน (Getting Started)

1. ติดตั้ง Dependencies:
   ```bash
   pnpm install
   ```
2. รัน Development Server:
   ```bash
   pnpm run dev
   ```
3. เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
   - ระบบจะพาไปที่หน้าเข้าสู่ระบบอัตโนมัติ
   - ล็อกอินด้วย: `admin` / `admin` (หรือบัญชีบุคลากร BRU SSO)
