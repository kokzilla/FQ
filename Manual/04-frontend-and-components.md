# บทที่ 4: ส่วนติดต่อผู้ใช้และคอมโพเนนต์ (Frontend & Components)

## 1. การทำงานของหน้าจอหลัก (Pages Walkthrough)

### 1.1 หน้าจอลงชื่อเข้าใช้ ([pages/login.vue](file:///d:/git/FQ/pages/login.vue))
- ออกแบบเป็น Minimal Card สะอาดตา
- รองรับทั้งการเข้าใช้งานผ่าน **BRU SSO (Single Sign-On)** ด้วยบัญชีของมหาวิทยาลัย และระบบ Admin สำรอง
- มีสถานะโหลด (Loading spinner) และแจ้งเตือนข้อผิดพลาดเมื่อรหัสผ่านไม่ถูกต้อง

### 1.2 หน้าแรกและภาพรวม ([pages/index.vue](file:///d:/git/FQ/pages/index.vue))
- แสดงการ์ดสถิติภาพรวม: จำนวนอาคารทั้งหมด, อาคารที่ตรวจแล้ว, และคะแนนเฉลี่ยรวม
- ตัวเลือกรอบการประเมิน (Evaluation Round Selector)
- แสดงรายการอาคารทั้งหมดพร้อมสถานะ:
  - `🟢 ตรวจแล้ว` พร้อมคะแนนและจำนวนกรรมการที่เข้าตรวจ
  - `⚪ ยังไม่ได้ตรวจ` พร้อมปุ่มกดเข้าสู่หน้าตรวจประเมินทันที

### 1.3 แบบฟอร์มตรวจประเมิน ([pages/evaluate/index.vue](file:///d:/git/FQ/pages/evaluate/index.vue))
- ส่วนหัว: เลือกอาคาร, รอบประเมิน, และแสดงชื่อผู้รับผิดชอบประจำอาคาร (แม่บ้าน)
- แสดงแบบสอบถามแบ่งตาม 7 หมวดหมู่ชัดเจน
- รองรับการกรอกข้อมูลแบบออฟไลน์: บันทึกข้อมูลที่กำลังกรอกลง `localStorage` อัตโนมัติทุกครั้งที่มีการเปลี่ยนคะแนน ป้องกันข้อมูลสูญหายหากหน้าเว็บหลุดหรือแบตเตอรี่หมด
- ส่วนที่ 2 ของแบบฟอร์ม: สรุปจุดเด่น, จุดที่ต้องปรับปรุงเร่งด่วน, และแผนการแก้ไข
- ส่วนลายเซ็นดิจิทัล: ให้กรรมการลงลายมือชื่อบนหน้าจอสัมผัสก่อนกดส่ง

### 1.4 หน้าจอรายงาน ([pages/reports/index.vue](file:///d:/git/FQ/pages/reports/index.vue))
- แท็บสลับดูรายงาน 2 มิติ: **รายงานสรุปรายอาคาร (Building Summary)** และ **รายงานสรุปรายบุคคล (Staff Summary)**
- แสดงกราฟิกแท่งคะแนนเฉลี่ยและ Badge เกรดประเมิน
- มีตารางเปรียบเทียบแนวโน้ม (Trend Indicators: 📈 เพิ่มขึ้น / 📉 ลดลง / ➖ คงที่)
- ปุ่มดาวน์โหลดรายงาน Excel สำหรับนำเสนอต่อผู้บริหาร

### 1.5 แผงควบคุมผู้ดูแลระบบ ([pages/admin/index.vue](file:///d:/git/FQ/pages/admin/index.vue))
- เข้าถึงได้เฉพาะผู้ใช้ที่มีบทบาท `role = 'ADMIN'`
- ประกอบด้วย 5 แท็บการจัดการ:
  1. **รอบการประเมิน**: สร้างรอบใหม่, สลับสถานะเปิด/ปิดรอบ
  2. **กำหนดคณะกรรมการ**: ค้นหาบุคลากรผ่าน BRU SSO แล้วแต่งตั้งเป็นกรรมการ
  3. **อาคารและแม่บ้าน**: จัดการอาคารและผูกรายชื่อแม่บ้าน
  4. **จัดการข้อคำถาม**: แก้ไข/เพิ่มข้อคำถามใน 7 หมวด
  5. **เกณฑ์คะแนนและระดับสี**: ปรับแต่งช่วงคะแนนสีเขียว/เหลือง/แดง

## 2. คอมโพเนนต์ที่นำกลับมาใช้ซ้ำ (Reusable UI Components)

### 2.1 [components/Navbar.vue](file:///d:/git/FQ/components/Navbar.vue)
- แถบนำทางด้านบน รองรับ Responsive:
  - เมนู Desktop: ลิงก์นำทาง `หน้าแรก`, `ตรวจประเมิน`, `รายงาน`, `ผู้ดูแลระบบ`
  - เมนู Mobile: แถบ Mobile Bottom Bar หรือ Hamburger Navigation สะดวกต่อการใช้นิ้วโป้งบนสมาร์ตโฟน
- แสดงชื่อ-สกุล และบทบาทของผู้ใช้งานที่กำลังล็อกอิน
- ปุ่มออกจากระบบ (Logout) เคลียร์คุกกี้และนำทางกลับไปหน้า `/login`

### 2.2 [components/QuestionCard.vue](file:///d:/git/FQ/components/QuestionCard.vue)
- แสดงโจทย์ข้อคำถามแต่ละข้อ พร้อมปุ่มเลือกคะแนนวงกลมขนาดใหญ่ `1`, `2`, `3`, `4`, `5`
- ปุ่ม **N/A (ไม่เกี่ยวข้อง)**: เมื่อกดเลือก ระบบจะตัดคะแนนเต็มของข้อนี้ออกจากตัวหารโดยอัตโนมัติ
- ช่องกรอก **ข้อบกพร่องที่พบเพิ่มเติม** แบบขยายได้เมื่อคะแนนต่ำกว่า 3

### 2.3 [components/ScoreSummaryBar.vue](file:///d:/git/FQ/components/ScoreSummaryBar.vue)
- แถบสรุปผลลอยติดขอบล่างของหน้าจอตรวจประเมิน (Floating Bottom Bar)
- คำนวณผลลัพธ์แบบเรียลไทม์ (Reactive Computed):
  - คะแนนที่ได้ / คะแนนเต็ม
  - ร้อยละ (%)
  - ระดับผลการประเมิน (Grade Badge พร้อมสีตามเกณฑ์)
  - ความคืบหน้าในการตอบข้อคำถาม (เช่น 32/35 ข้อ)

### 2.4 [components/SignaturePad.vue](file:///d:/git/FQ/components/SignaturePad.vue)
- พัฒนาต่อยอดจากไลบรารี `signature_pad`
- รองรับการวาดเส้นลายเซ็นด้วยนิ้วสัมผัสหรือปากกาสไตลัส
- มีปุ่ม "ล้างลายเซ็น" เพื่อเริ่มวาดใหม่
- แปลงลายเซ็นเป็น Base64 PNG Data URL ส่งให้กับ Form Submission

## 3. ระบบรักษาความปลอดภัยฝั่งไคลเอนต์ ([middleware/auth.global.ts](file:///d:/git/FQ/middleware/auth.global.ts))

- ตรวจสอบคุกกี้ Session ของผู้ใช้งานทุกครั้งที่มีการเปลี่ยนหน้า (Route Navigation)
- หากยังไม่ได้ยืนยันตัวตน และพยายามเข้าหน้าอื่นที่ไม่ใช่ `/login` จะถูก Redirect ไปยัง `/login` ทันที
- มีการตรวจสอบระดับบทบาท: หากผู้ใช้ทั่วไปพยายามเข้าหน้า `/admin` ระบบจะแจ้งเตือนและส่งกลับไปที่หน้าแรก
